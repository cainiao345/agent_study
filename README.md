# 我的个人系统

> 任何 AI 助手第一次接触本系统时，请先读完本文件，再读 profile/ 目录，然后才开始对话。

## 这是什么
一个完全本地、纯文本的个人系统。所有数据以 Markdown（.md）格式保存，
换任何 AI 工具都能无缝接手，数据永远属于你自己。

## 目录说明
| 目录 | 作用 |
|---|---|
| profile/ | 我的基本情况和目标，AI 必读 |
| journal/ | 每日记录（系统的燃料），看最近 7 天即可了解我的近况 |
| projects/ | 进行中的重要项目（有截止日的单个事项），每个项目一个文件 |
| learn/ | 学习系统（变现主线）：技能树 S1-S5、复习卡、错题本、教练入口 |
| trading/ | 股票交易日志与模板 |
| health/ | 健康数据（睡眠、运动、饮食） |
| reviews/ | 周期性复盘结论，系统的精华沉淀在这里 |
| inbox/ | 未整理的临时记录，每周清空一次 |
| templates/ | 日记、周报、项目、交易日志、交易月报的模板 |
| _archive/ | 归档的旧版本文件，保留备查，不再作为行动依据 |

## 协作规则（请 AI 遵守）
1. 回答前先读 profile/，并结合 journal/ 最近的真实记录给建议，不要给放之四海皆准的通用答案。
2. 每次对话结束时，把需要保存的结论用 Markdown 格式输出，我会存回对应文件。
3. 如果我的记录之间、或记录与目标之间存在矛盾，请直接指出，不用照顾我的情绪。
4. 每周日复盘时，阅读最近 7 天 journal，输出周报。

## 怎么开始
1. 打开 profile/about-me.md，把内容填成你自己的情况。
2. 打开 profile/goals.md，写下目标（可以是模糊的）。
3. 每天点左侧“日记”图标 → 新建当天日记，3 分钟写完。
4. 每周日新建一篇 reviews 周报，把最近 7 天日记发给 AI 做复盘。
5. 对话前必须阅读 laws.md；给我任何计划或建议时，逐条对照已验证定律，冲突时指出来
